# Calculator
Simple Python Calculator

A lightweight, command-line calculator program written in Python that handles fundamental arithmetic operations.

Features

Basic Operations: Supports addition, subtraction, multiplication, and division.

Error Handling: Safe division operation preventing crashes when dividing by zero.

Input Validation: Gracefully handles non-numeric user inputs.

Prerequisites

To run this program, you need Python installed on your system.

Python 3.x
